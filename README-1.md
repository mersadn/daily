# برنامه هفتگی من (PWA)

یه برنامه‌ریز هفتگی/روزانه ساده که کاملاً توی گوشیت (آفلاین) کار می‌کنه و اطلاعاتش رو توی خود مرورگر (localStorage) نگه می‌داره.

## فایل‌ها
- `index.html` — کل اپ (ظاهر + منطق)
- `manifest.json` — مشخصات نصب پی‌دبلیو‌ای
- `sw.js` — سرویس‌ورکر برای کارکرد آفلاین
- `icon-192.png`, `icon-512.png` — آیکون‌ها

همه فایل‌ها باید مستقیم توی ریشه‌ی ریپازیتوری (root) باشن، نه توی پوشه‌ی جدا.

## راه‌اندازی روی GitHub Pages
1. یه ریپازیتوری جدید بساز (مثلاً `weekly-planner`).
2. این ۵ فایل رو مستقیم توی ریشه‌ی ریپازیتوری آپلود کن (drag & drop توی صفحه‌ی GitHub کافیه).
3. برو به `Settings > Pages`.
4. توی بخش `Source`، شاخه‌ی `main` و پوشه‌ی `/root` رو انتخاب کن و Save بزن.
5. بعد چند دقیقه، آدرسی مثل زیر فعال میشه:
   `https://USERNAME.github.io/weekly-planner/`

## نصب روی گوشی
- **اندروید (کروم):** آدرس بالا رو باز کن، از منو گزینه‌ی «Add to Home screen» یا بنر پایین صفحه رو بزن.
- **آیفون (سافاری):** آدرس رو باز کن، دکمه‌ی Share رو بزن، بعد «Add to Home Screen».

بعد از نصب، برنامه مثل یه اپ مستقل روی گوشیت اجرا میشه و حتی آفلاین هم کار می‌کنه.

## نکته درباره‌ی داده‌ها
اطلاعات فقط روی همون گوشی/مرورگری که باهاش استفاده می‌کنی ذخیره میشه (localStorage). اگه مرورگر رو عوض کنی یا کش رو پاک کنی، داده‌ها از بین میره. اگه بعداً خواستی، می‌تونیم sync ابری هم بهش اضافه کنیم.
